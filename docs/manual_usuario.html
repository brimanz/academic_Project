Sistema de Inventario Moderno

Versión 1.0

1. Introducción

Bienvenido al Sistema de Inventario Moderno. Esta aplicación web permite gestionar de manera eficiente productos, proveedores y usuarios.

2. Requisitos del Sistema

  • Apache 2.4+ o Nginx
  • PHP 7.4 o superior
  • MySQL 5.7+ o MariaDB 10.3+
  • Extensión PDO MySQL habilitada

3. Instalación

1 Descargar los archivos

Coloque todos los archivos en la carpeta raíz de su servidor web.

2 Crear la base de datos

Ejecute el archivo sql/database.sql en phpMyAdmin.

3 Configurar la conexión

Edite config/config.php y actualice las credenciales de la base de datos.

4 Acceder al sistema

Abra su navegador y acceda a la URL donde instaló el sistema.

5. Uso del Sistema

5.1 Iniciar Sesión

  1. Abra la página principal del sistema
  2. Ingrese su correo electrónico
  3. Ingrese su contraseña
  4. Haga clic en "Iniciar Sesión"

5.2 Dashboard Principal

  • Banner de bienvenida: Mensaje personalizado
  • Tarjetas de estadísticas: Resumen del sistema
  • Alertas de stock bajo: Productos que requieren reposición

5.3 Gestión de Productos

Desde el módulo de productos puede:

  • Agregar nuevos productos
  • Editar productos existentes
  • Ver detalles de cada producto
  • Eliminar productos (eliminación lógica)
