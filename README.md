## 🎯 Descripción del Proyecto

**Centro Óptico La Económica F.P.** es un **software de gestión para ópticas** y centros de optometría que permite administrar de forma eficiente el inventario de productos ópticos, el registro de proveedores de lentes, la gestión de empleados, el control de usuarios y la organización por categorías de monturas, cristales y accesorios de salud visual.

Este **sistema web para ópticas** fue diseñado pensando en la experiencia de usuario (UX/UI), incorporando tendencias actuales como el **diseño glassmorphism**, **animaciones CSS3 avanzadas**, **transiciones profesionales** y una **interfaz 100% responsive** que se adapta perfectamente a computadoras, tablets y smartphones.

Ideal para ópticas, centros de salud visual, clínicas de optometría y negocios de venta de lentes correctivos en Venezuela y Latinoamérica.

## ✨ Características Principales

| Característica | Descripción |
|----------------|-------------|
| 🎨 **Glassmorphism UI** | Tarjetas y formularios con efecto de cristal esmerilado, bordes luminosos y transparencia moderna |
| 📱 **Diseño Responsive** | Adaptación perfecta a móviles, tablets y escritorio con menú hamburger animado |
| 🧭 **Navegación Intuitiva** | Menú desplegable con dropdowns animados y transiciones suaves |
| ⚡ **Animaciones Avanzadas** | Fade-in, slide-up, staggered loading, hover lifts y fondos decorativos animados |
| 🎨 **Paleta Minimalista** | Colores sobrios en slate, blanco cristal y azul royal que resaltan cada elemento |
| 🔒 **Sistema de Login** | Pantalla de inicio de sesión con validación visual y redirección al dashboard |
| 📊 **Tablas de Datos** | Visualización profesional de inventario, proveedores y categorías con scroll horizontal en móviles |
| 🏢 **Información Empresarial** | Sección institucional con misión, visión e historia de la óptica |

## 🛠️ Tecnologías Utilizadas

- **HTML5** semántico y accesible
- **CSS3** con variables personalizadas, Flexbox, Grid y Media Queries
- **JavaScript Vanilla** para interactividad del menú y dropdowns
- **Diseño Mobile-First** optimizado para SEO técnico
- **Arquitectura de componentes** con CSS compartido (`estilos-globales.css`)
